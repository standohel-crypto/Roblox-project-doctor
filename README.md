# Roblox Project Doctor

Roblox Project Doctor — независимый браузерный инструмент для проверки скриптов Roblox на языке Luau.

Открыть инструмент: https://roblox-project-doctor.onrender.com/page/

## Что он делает

Пользователь вставляет код Luau в браузере и получает найденные проблемы с номерами строк.

- обычная проверка использует Luau LSP с определениями Roblox;
- проверяются синтаксис и типы, а для знакомых сообщений доступны объяснения и советы на русском;
- оригинальное сообщение анализатора можно раскрыть отдельно;
- по желанию можно включить дополнительный разбор логики с ИИ.

При включённом ИИ исходный код отправляется сервису Groq. Без включения этой функции запрос к Groq не выполняется.

## Небольшой пример

В этом коде `print(reward)` выводит `100`, хотя автор ожидает `200`:

```lua
local reward = 100
local hasVIP = true

if hasVIP then
    local reward = reward * 2
end

print(reward)
```

Внутри `if` создаётся другая локальная переменная `reward`. Для изменения внешней переменной второй `local` нужно убрать.

## Ограничения

Инструмент не запускает игру и не видит все объекты и связанные скрипты проекта. Отсутствие диагностик не гарантирует отсутствие ошибок. ИИ может ошибаться или быть временно недоступен, поэтому его предложения нужно проверять в Roblox Studio.

Обычный статический анализ также доступен в Roblox Studio. Project Doctor удобен для отдельной проверки в браузере, русских объяснений знакомых сообщений и дополнительного разбора с ИИ.

Roblox Project Doctor — независимый проект, не официальный продукт Roblox.

## Для разработчиков

1. Сделай резервную копию проекта. Скопируй server.js, client/form.js и файлы analyzer из этого архива в одноимённые папки своего проекта. Твои page.html/style.css, definitions, node_modules и package.json остаются на месте. Старый doctor-ai.js больше не вызывается.
2. Рядом с server.js создай файл .env по образцу .env.example. В GROQ_API_KEY вставь свой полный ключ локально. Не помещай .env в client. Если используешь Git, добавь .env и data/ в свой .gitignore. Реальный ключ в архив не включён.
3. Останови старый сервер Ctrl+C. Из папки проекта запусти:

   node --env-file=.env server.js

4. Открой http://localhost:3005/page и нажми Ctrl+F5.
5. Отметь «Включить ИИ при анализе» и запусти проверку. Без галочки браузер не вызывает /api/review и код не отправляется Groq. Галочка по умолчанию выключена.

Ответ ИИ расположен первым, перед результатом Luau и обычными карточками. Запросы независимы и идут параллельно: сбой или 429 от Groq не скрывает результат Luau, а сбой Luau не скрывает ответ ИИ. Уже готовый результат отображается, пока второй ещё загружается. Кнопка освобождается после завершения обоих запросов. Ключ существует только на сервере, модель работает у Groq, не на ПК. Сам Express и Luau пока работают на твоём ПК, пока проект не размещён на сервере.

Встроенный запрос модели находится в analyzer/groq.js: максимум пять конкретных замечаний по DRY, KISS, YAGNI, SOLID/SRP, безопасности Roblox, событиям/ресурсам, производительности и читаемости. Ответ — текст; код из ответа не исполняется, HTML не вставляется. При переключении языка уже полученный ответ не переводится автоматически; интерфейс предлагает повторить анализ на выбранном языке.

Лимита «5 в день», аккаунтов и идентификации пользователей нет. Это не отменяет лимитов провайдера: все посетители расходуют квоту одного серверного ключа. При 429 показывается уведомление. Автоматических повторных запросов нет. Длина исходного кода ограничена 50 КБ, ожидание Groq — 35 секунд. На бесплатном тарифе большой скрипт может не пройти токенную квоту даже при размере меньше 50 КБ. Не включай платный тариф, если нужны только бесплатные запросы.

Отзывы идут на /api/feedback и сохраняются в data/feedback.jsonl. Оценки ИИ имеют ruleId ai-groq-review. Модель автоматически на этих оценках не обучается.

Проверка: один запрос с выключенной галочкой, один с включённой; выключи или временно убери ключ, убедись, что Luau продолжает работать. Перед публичным выпуском требуется отдельная проверка изоляции Luau и нагрузки: этот пакет не публикует сайт и не обещает неограниченную доступность.

Документация: https://console.groq.com/docs/openai
Лимиты: https://console.groq.com/docs/rate-limits

Проверено здесь: синтаксис JS, отсутствие запроса ИИ без галочки, порядок блоков, отображение семи карточек, независимость ошибок Luau/Groq, обработка 401/429/500 и таймаута, безопасный текстовый вывод. Проверки выполнены с имитацией HTTP и DOM. Реальный запрос Groq не выполнялся: рабочего полного ключа здесь нет.

Project Doctor — оферта и политика, 02.10.2026

1. Распакуйте архив в корень АКТУАЛЬНОЙ копии проекта, рядом с package.json.
2. В терминале этой папки выполните:
   node install-legal.mjs
3. Скрипт добавит ссылки в существующую страницу и сохранит её исходник в page-before-legal.html.bak.
   Повторный запуск не создаёт дубликатов. Он не изменяет сервер, аккаунты, темы или анализатор.
4. Отправьте только эти три файла:
   git add -- client/offer.html client/privacy.html client/page.html
   git commit -m "Add public offer and privacy policy"
   git push origin main
   Если Git выдаст ошибку, остановитесь и пришлите вывод. Не используйте force push.
5. Дождитесь успешного деплоя Render (автоматического, если он включён).
6. Откройте обе страницы и проверьте ссылки внизу сайта:
   https://roblox-project-doctor.onrender.com/offer.html
   https://roblox-project-doctor.onrender.com/privacy.html
